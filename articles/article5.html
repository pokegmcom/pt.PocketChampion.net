Códigos de Resgate do PocketChampion Agosto 2026: Festival Qixi e Recompensas SummerSurge

18 de agosto de 2026

Procurando os últimos códigos de resgate do PocketChampion? Reunimos todos os códigos ativos de agosto de 2026, incluindo as recompensas do evento Festival Qixi, um código Shiny por tempo limitado e o pacote exclusivo da zona SummerSurge. Resgate-os agora antes que expirem!

Códigos de Presente do Festival Qixi

Celebre o Festival Qixi com dois códigos especiais. Ambos são válidos para todos os servidores internacionais.

  • Código: I ???? POKEMON — Recompensa: Luvdisc Shiny×1. Válido: 19/8 00:00 - 25/8 23:59 (UTC+8).
  • Código: LOVE — Recompensa: Alcremie Shiny×1. Válido: 19/8 00:00 - 25/8 23:59 (UTC+8).

Código Shiny

Um código Shiny de curta duração está disponível para todos os servidores. Certifique-se de resgatá-lo rapidamente.

  • Código: WSPFK5T6 — Recompensa: Perfume Atrai-Insetos×1. Válido: 2026-08-17 00:00 - 2026-08-18 23:59 (UTC+8).

Código da Zona SummerSurge

A zona SummerSurge abre em 15 de agosto. Use este código no servidor SummerSurge para obter recompensas exclusivas.

  • Código: SummerSurge — Recompensas: Walking Wake (Não Shiny)×1 e Tickets Gacha×10. Válido: 2026-08-15 00:00 - 2026-08-21 23:59 (UTC+8).

Como Resgatar os Códigos

  1. Abra o PocketChampion e toque no ícone de Configurações no canto superior direito.
  2. Selecione "Resgatar Código" no menu de configurações.
  3. Digite o código exatamente como mostrado e toque em "Resgatar".
  4. Verifique sua caixa de correio no jogo para coletar as recompensas.

Notas Importantes

  • Cada código só pode ser usado uma vez por personagem.
  • Os códigos têm datas de validade — resgate-os o quanto antes.
  • Certifique-se de estar no servidor correto para códigos específicos de zona.
